# Traceback

A voice-first personal agent for preserving thoughts and references and managing persistent memory alongside tasks, lists, and reminders through its own UI and MCP.

This workspace contains planning documents and initial UI mockups. The first implementation will run locally on a PC with PostgreSQL, a REST API, and local MCP access. Backend implementation has not started.
