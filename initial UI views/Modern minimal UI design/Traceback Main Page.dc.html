Binary Search Trees

Left less than node less than right. Search, insert, delete: O(log n) average, O(n) if unbalanced.

Trees

A tree is a hierarchical, acyclic structure — one root, and every other node reachable by exactly one path.

Binary Search Trees

Left subtree < node < right subtree. Search, insert, delete average O(log n) — degrades to O(n) if unbalanced.

Traversals

— In-order: left, node, right (sorted output on a BST)
— Pre-order: node, left, right
— Post-order: left, right, node

Balancing

AVL trees bound height via rotations after insert/delete. Red-black trees relax the balance factor for cheaper writes.
