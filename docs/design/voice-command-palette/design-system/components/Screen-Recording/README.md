Recording state of the voice command panel, shown while the user holds the global shortcut. Compact, unmistakable, never obscures the app underneath.

- Dock: fixed 460px panel, bottom-center of the content area, 32px from the bottom edge.
- Recording dot pulses (`ink-faint` fallback under reduced motion — never the only indicator, the label "Recording…" always shows too).
- Waveform is decorative (`aria-hidden`); the elapsed timer is the accessible signal of activity.
- Footer hints are literal key names, not icons alone: "Release ⌥ Space to send · Esc to cancel".
- The Tasks screen underneath stays fully visible and interactive-looking; no scrim, no blur.
