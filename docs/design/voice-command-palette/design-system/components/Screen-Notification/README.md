Native macOS notification used whenever the shortcut is triggered while another app is focused — Traceback never steals focus for a simple result.

- Only for results a person can act on with one click: a count, a short quoted command, and a single action label.
- Clicking the notification opens Traceback directly at the relevant result or clarification panel — never at a blank home screen.
- Ambiguous matches get their own notification copy (see Notification / Ambiguity) that sends the user straight to the clarification state instead of guessing.
